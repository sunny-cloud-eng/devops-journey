## 🏆 Featured Project: UptimeGuard

**A website monitoring tool with a complete end-to-end DevOps pipeline.**

UptimeGuard checks whether websites are UP or DOWN, measures response times, and shows results on a live auto-refreshing dashboard. It solves a real business problem — every company needs to know if their services are online.

### 🎯 Full DevOps Pipeline

| Layer | Technology | What It Shows |
|-------|-----------|---------------|
| 🐍 Application | Python (Flask) | Dashboard, /health endpoint, JSON API |
| 🐳 Containerization | Docker | Dockerfile with best practices |
| ⚓ Orchestration | Kubernetes | Self-healing deployment + health probes |
| 🏗️ Infrastructure | Terraform | Infrastructure as Code |
| 🔄 Automation | GitHub Actions | CI/CD pipeline: test → build → validate |
